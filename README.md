# monorepo

All projects in one place — Telegram bots, web apps, infrastructure, tools.

## Structure

```
github/          # Projects with their own GitHub repos
  asf-shop/      # Nexo Shop — Telegram digital goods store
  botauto-ckstr/ # Bot automation
  botshop/       # SOUS MARKET — main marketplace bot
  chessbot/      # Rich Text Chess & Checkers for Telegram
  createcoin-main/ # Memecoin launcher (Solana)
  nakrut/        # Telegram engagement bot
  rassil/        # LZT Telegram buyer
  x-com/         # X.com tools

local/           # Local-only projects
  bot-farm/      # Bot fleet manager
  vpn-panel/     # VPN shop bot with built-in panel
  support-ai/    # AI support agent (DeepSeek)
  frontend-kit/  # Shared TG mini-app UI kit
  ...and 30+ more
```
