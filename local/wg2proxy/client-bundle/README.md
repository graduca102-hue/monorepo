# WG-as-SOCKS client bundle (unlimited-1month-009)

Локальный SOCKS5/HTTP-прокси поверх WireGuard-туннеля. Пакеты браузера
летят через WG **end-to-end**, TLS/TCP/WebRTC — родные клиента. Для антифрода
неотличимо от обычного WG-подключения.

## Что внутри

- `wireproxy.exe` — единый бинарник, WG-стек в юзерспейсе (Windows x64)
- `wireproxy.conf` — конфиг (WG-пир + локальный SOCKS)
- `run.bat` — запуск с окном консоли (видно логи, закрыл окно — прокси
  остановился)
- `run-hidden.vbs` — запуск в фоне без окна (стоп через Диспетчер задач →
  `wireproxy.exe` → Снять задачу)

## Как пользоваться

1. Распакуй папку куда угодно (права администратора не нужны).
2. **Важно:** выключи этот же WG-конфиг везде, где он ещё поднят
   (WireGuard-приложение на этом ПК, на телефоне, на роутере). Один ключ =
   одно активное подключение — иначе будут рваться оба.
3. Запусти `run.bat` (или `run-hidden.vbs` для фона).
4. В браузере / антидетекте / любом приложении укажи:

   ```
   SOCKS5://127.0.0.1:1080
   user: wgp009
   pass: s4QrnxLzkjaB3F5S
   ```

5. Проверка — открой https://ifconfig.co/ (через тот же браузер/приложение).
   Должен показать `212.118.40.188`, Netherlands, vdsina.

## Настройка в Chrome / Firefox

Chrome сам SOCKS5 с логином/паролем не любит. Варианты:

- **FoxyProxy** (расширение) — задать SOCKS5 `127.0.0.1:1080` + креды.
- **Firefox** — Settings → Network → SOCKS v5, `127.0.0.1` `1080`, галка
  "Proxy DNS when using SOCKS v5". Логин/пароль спросит при первом коннекте.
- **Антидетект-браузеры** (Multilogin, GoLogin, AdsPower) — стандартное
  поле «SOCKS5» с логином и паролем.

## HTTP-прокси (если нужно)

Раскомментируй в `wireproxy.conf` секцию `[http]` и перезапусти — на
`127.0.0.1:1081` появится HTTP-прокси с теми же кредами.

## Автозапуск при входе в Windows

Скопируй `run-hidden.vbs` (или ярлык на него) в:

```
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup
```

## Диагностика

- «connection refused» на 1080 → wireproxy не запущен, посмотри `run.bat`
  на ошибки.
- Прокси коннектится, но IP не меняется → у тебя ещё где-то поднят этот
  же WG-конфиг, отруби его.
- Прокси коннектится, IP правильный, но сайты фродят — проверь
  WebRTC-leak: https://browserleaks.com/webrtc. В Chrome без extension
  WebRTC утекает мимо SOCKS. Ставь uBlock Origin или расширение
  "WebRTC Leak Prevent".

## Что это НЕ решает

- Репутацию IP — `212.118.40.188` в базах помечен как `hosting/vpn`
  (vdsina, AS216071). Против сервисов, которые режут все VPN, это не
  спасёт. Для таких мест нужны резидентные/мобильные IP.
- «Один ключ — одно устройство» на стороне провайдера WG. Параллельно
  этот же конфиг с двух мест — оба рвётся.
