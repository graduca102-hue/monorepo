# perebiraika — приватный отсеиватель быстрых RU-прокси maskify

**Только для владельца.** Ни в один клиентский бот не подключён, кроме этой
папки и `/opt/perebiraika/` на srv2 никаких следов не оставляет.

## Что делает

Крутится фоновым циклом на srv2, каждую итерацию:

1. Берёт свежий session-id и подключается к RU-ротирующему шлюзу maskify
   через собственный служебный субпул (`perebiraika-<hex>@sous-market.com`).
2. Проверяет geo через ip-api.com (~300 B) — оставляет только `RU`.
3. Скачивает 64 KB с `speedtest.selectel.ru` (Range-запрос), считает Mбит/с.
4. Если скорость ≥ порога — сохраняет запись
   `{sid, ip, mbit, expires_at}` в `data/pool.json` как sticky-линию с
   TTL 300s (30s буфер на выдачу).
5. Если медленно или неверная страна — выбрасывает, дальше.

Пул саморегулируется: как только в живых `pool_size` линий, цикл спит.
Есть жёсткий бюджет `BUDGET_MB_PER_HOUR = 40 MB/час` — при превышении цикл
приостанавливается, реселлерский GB-пул шопа не сливается.

## Управление

Все команды — на srv2 из `/opt/perebiraika/`:

```bash
V=/opt/perebiraika/venv/bin/python
P=/opt/perebiraika/perebiraika.py

$V $P start                  # включить цикл (сервис уже запущен, включает флаг)
$V $P stop                   # выключить цикл, пул сохраняется
$V $P status                 # что в пуле, что за час, кто субпул
$V $P get 10                 # выдать 10 быстрых линий (host:port:login:password)
$V $P threshold 12           # поднять порог до 12 Мбит/с (все медленные из пула вылетят)
$V $P size 25                # держать в пуле до 25 линий
$V $P reset                  # очистить пул (сессии наберутся заново)
```

Формат выдачи:

```
proxy.sousmarketfranchize.shop:80:<user>-cc-RU-s-<sid>-ttl-300:<pass>   # exit=… X.X Мбит/с осталось NNNs
```

Это стандартный `host:port:login:password`. Живёт до `expires_at`
(≈ 4.5 минуты после отбора). Один и тот же exit держится через `-s-<sid>`.

## Установка / переустановка (на srv2)

Файлы кладутся в `/opt/perebiraika/`, `.env` создаётся автоматически из
`/opt/botshop/.env` (берётся только `MASKIFY_RESELLER_API_KEY`):

```bash
bash /opt/perebiraika/deploy.sh
```

Скрипт: ставит venv + aiohttp, регистрирует systemd `perebiraika.service`,
запускает демон. По умолчанию цикл выключен (`enabled=false`) —
включаем командой `start`, когда нужно.

## Стоимость

- Служебный субпул maskify — начальная аллокация 1 GB, авто-топап +1 GB при
  падении ниже 0.15 GB. При бюджете 40 MB/час это ~1 GB/сутки максимум.
- Каждая выданная быстрая линия для нашего использования тратит GB реально —
  это резидентка, обойти нельзя.
- Просмотр статуса и `get` ничего не тратят, только читают локальный `pool.json`.
