1. Куки в JSON импортировать расширением Cookie Editor (Import → вставить JSON), находясь на нужном домене.
2. Домен браузера должен совпадать с доменом куки, иначе импорт не сработает.
3. В антидетекте (Dolphin, AdsPower) куки вставляются в поле Cookies профиля, а не импортом .txt.
4. Сначала куки, потом открывать сайт. Вход логином/паролем поверх кук ломает сессию.

### Вход по токену / API data
1. Токен и «API data» — для импорта в софт (Instagram Account Manager, InstaFy и т. п.), не для браузера.
2. В браузер такой аккаунт заходит только логином/паролем или куками.

### Telegram: tdata / session
1. `tdata` кладётся в папку рядом с `Telegram.exe` (портабельная версия), старый профиль удалить.
2. `.session` открывается только поддерживающим её софтом.
3. Если в описании товара сказано, что номер и код выдаёт ТП — эскалация, код выдаёт оператор.

## Аккаунты: симптом → алгоритм

### «Просит SMS / код на телефон / подтверждение номера»
1. Проверить прокси: гео должно совпадать с гео регистрации.
2. Попробовать «Try another way» → подтверждение по почте.
3. Если в комплекте есть резервная почта — взять код там.
4. Если проверка требует номер сразу, до входа, и почты в комплекте нет — эскалация, товар считается невалидным.

### «Неверный пароль» / «пароль изменён N дней назад»
1. Проверить, что скопирована вся строка, без лишнего пробела и разделителя.
2. Проверить, что пароль взят из правильного поля формата.
3. Пароль действительно не подходит — эскалация, аккаунт невалиден.

### «Аккаунт заблокирован / заморожен / не существует»
1. Уточнить, когда сломался: до первого входа или после работы клиента.
2. До первого входа — эскалация, товар невалиден.
3. После заливов, рассылок, массовых действий — брак не признаётся.

### «2FA не подходит»
1. Убедиться, что вводится 6-значный код из аутентификатора, а не сам ключ.
2. Проверить синхронизацию времени.
3. Не помогло — эскалация.

### «Не соответствует описанию» (нет БМ/РК, другой год рега, нет друзей/постов, нет почты, нет 2FA)
1. Запросить номер заказа и скриншот расхождения.
2. Эскалация. Это основание для возврата или замены.

### «Из N аккаунтов X нерабочих»
1. Запросить номер заказа и список нерабочих строк.
2. Эскалация: частичный возврат по количеству.

### «Почта не принимает вход / коды не приходят»
1. Проверить адрес входа: Rambler — `mail.rambler.ru/auth`, GMX — `gmx.com`, Outlook/Hotmail — `outlook.com`.
2. Проверить, что вводится пароль от почты, а не от аккаунта соцсети.
3. Проверить гео прокси.
4. Не помогло — эскалация.

## Прокси: резидентские (собственный шлюз)

### База
1. Шлюз `proxy.sousmarketfranchize.shop:80`, только HTTP CONNECT. SOCKS5 в этом пуле не поддерживается — при выборе всё равно выдаётся HTTP.
2. HTTPS-сайты работают через ту же HTTP-строку. Писать `https://` перед адресом прокси нельзя.
3. Оплата за трафик (GB). В главном боте цена 0.63 $ за 1 GB, во франшизных ботах выше на наценку владельца бота. Актуальная цена всегда на кнопке «Резидентские | X$/GB».
4. Покупка от 0.1 до 10000 GB и не больше остатка поставщика: бот пишет «Можно купить: X GB». «Нет трафика» = у поставщика пусто, ждать пополнения.
5. Трафик по времени не сгорает, тратится по факту. Срока аренды у GB-трафика нет.

### Как получить прокси
1. Меню «⭐ Прокси» → «Резидентские».
2. «☁️ Пополнить трафик» → количество GB → оплата.
3. Настроить: Страна / Сессия / Ротация / Формат / Протокол / Количество.
4. «📄 Получить прокси» → .txt со списком строк.

### Настройки
- **Страна**: список, поиск по коду или названию, «🌍 Любая» = микс всех стран.
- **Сессия**: `Ротация по запросу` — IP меняется на каждом новом соединении; `Фиксированная сессия` — строка держит один IP.
- **Ротация** (для фиксированной сессии): По запросу / 5 / 15 / 30 / 60 минут.
- **Формат**: `login:password@host:port`, `host:port:login:password`, `host:port@login:password`, `protocol://login:password@host:port`.
- **Количество**: 5 / 25 / 50 / 100 или своё, 1–10000.
- **🔐 Пароль**: смена пароля суб-аккаунта.
- **🗑 Сбросить**: настройки по умолчанию.

### Как читать строку
`http://<логин>-cc-US-s-<сессия>-ttl-900:<пароль>@proxy.sousmarketfranchize.shop:80`
- `-cc-XX` — страна (ISO-2).
- `-s-…` — фиксированная сессия (в режиме ротации отсутствует).
- `-ttl-N` — время удержания IP в секундах.
- Хост `proxy.sousmarketfranchize.shop`, порт `80`, остальное — логин и пароль.

### Ошибка 407 / постоянное окно авторизации
1. Причина №1: нажата «🔐 Пароль» — после смены пароля все ранее выданные строки мертвы.
2. Решение: «📄 Получить прокси» заново и заменить все строки в софте.
3. Проверить, что логин скопирован целиком, вместе с тегами `-cc-`, `-s-`, `-ttl-`.

### Ошибки 400 / 405, «не открывает ни один сайт»
1. Проверить остаток GB в меню «⭐ Прокси».
2. 0 GB → купить трафик, строки заработают сразу.
3. Трафик есть — эскалация с user ID и строкой без пароля.

### Соединение рвётся каждые 5–30 секунд, слетает авторизация в софте
1. Причина: режим «Ротация по запросу» — IP меняется на каждое соединение, залогиненные сессии рвутся.
2. Решение: Сессия → «Фиксированная сессия», Ротация → 30 или 60 минут, затем «📄 Получить прокси» заново.

### «Выдаёт одни и те же прокси»
1. Так задумано: список закреплён за клиентом и выдаётся повторно, пока IP живы.
2. Новый список — изменить любую настройку (страна, режим, количество, формат, TTL) и нажать «📄 Получить прокси».

### Гео не совпадает
1. Проверить, что в строке есть `-cc-<КОД>` нужной страны.
2. Перевыпустить список (сменить настройку → «Получить прокси»).
3. Повторяется — эскалация со строкой и скрином чекера.

### «Трафик улетел слишком быстро»
1. Считаются все переданные байты: видео, рилсы, медиа, повторные попытки софта.
2. Параллельные потоки тратят GB кратно.
3. Расход сверяется по остатку в меню до и после задачи; при явной аномалии — эскалация с user ID, датой и описанием задачи.

### Высокий пинг / не грузятся сайты на конкретном гео
1. Сменить страну и перевыпустить список.
2. Проверить, что в софте указан HTTP-прокси, а не SOCKS5.
3. Для мобильных клиентов проверить поддержку HTTP-прокси с авторизацией.

### Порты и протоколы
1. Шлюз слушает `:80`, CONNECT работает на любой порт назначения (443, 587, 465 и т. д.).
2. UDP не поддерживается.
3. Гарантий по SMTP-портам нет; перед оптовой покупкой — эскалация.

### Срок действия купленных прокси
1. Резидентский трафик (GB) не имеет срока, живёт до расхода.
2. Поштучно купленные прокси (карточка заказа и прокси-менеджер в mini-app) имеют дату окончания. Если поставщик её не прислал, считается 14 дней с покупки.
3. Прокси перестали работать раньше даты окончания — эскалация с номером заказа и строкой.

## Прокси: Proxyma (ISP и мобильные)

1. «🏠 Статика ISP | IP» — статичный резидентский IPv4, свой IP на весь срок аренды (по умолчанию 30 дней). Покупка: тариф → назначение (площадка) → страна → количество.
2. «📱 Мобильные | GB» — IP сотовых операторов, ротация по запросу, оплата за трафик.
3. Тариф выбирается под конкретную площадку; работа на другой площадке не гарантируется.
4. Если тариф не опубликован поставщиком, покупка отбивается до списания — баланс не трогается.

## Прокси: сторонние сервисы (9Proxy, PIA, 922, ABC, Proxy 001, 711, CliProxy, LokiProxy)

1. Продаются пакеты GB или IP. Выдаётся ключ/промокод активации, а не готовая строка прокси.
2. Ключ активируется на сайте самого сервиса, в кабинете клиента, там же выпускаются прокси.
3. Инструкции: 9Proxy — `https://telegra.ph/Kak-aktivirovat-9Proxy-promokod-12-18`; CliProxy — `https://telegra.ph/Kak-aktivirovat-CLiProxy-promokod-02-06`; 711 Proxy — `https://telegra.ph/Kak-aktivirovat-711-Proxy-promokod-07-12`; Proxy 001 — `https://telegra.ph/Kak-aktivirovat-Proxy-001-promokod-07-13`.
4. Остальные сервисы: регистрация на сайте сервиса → раздел активации кода / пополнения → ввести выданный ключ.
5. «Прокси временно недоступны» / «Not available» = нет остатка у поставщика. Эскалация на возврат.
6. Ротация, гео и формат настраиваются в кабинете стороннего сервиса, не в нашем боте.

## SMS-активации

1. Покупка номера — в mini-app раздела SMS: сервис → страна → номер.
2. Код приходит в карточку активации; «Запросить новый код» доступен после первого.
3. **Отмена возможна только через 2 минуты после покупки.** Раньше бот пишет, сколько ждать.
4. После получения SMS отмена невозможна, деньги не возвращаются.
5. Отмена до получения кода → возврат на баланс автоматически.
6. Номер отменил поставщик → возврат автоматический.
7. Зависшие активации старше 20 минут закрываются фоново с возвратом.
8. «provider_error», «обновите список», номер не покупается — у поставщика нет номеров на этот сервис; деньги не списываются либо возвращаются.
9. Деньги списаны, кода нет, активация закрыта без возврата — эскалация: user ID, сервис, номер, время.

## Email-активации

1. Покупается адрес под конкретный сайт: указать сайт → домен → получить адрес.
2. Письмо ждать в карточке активации; «Письмо ещё не пришло» = ждать и нажать проверку позже.
3. Отмена до получения письма → возврат на баланс. После получения письма отмена недоступна.
4. Повторный заказ письма на тот же адрес доступен после завершения активации.
5. «Этот адрес больше нельзя использовать повторно» — адрес забанен поставщиком, брать новый.
6. «Для выбранного домена закончились адреса» — выбрать другой домен.
7. Письмо пришло обрезанным или без кнопки-ссылки — нажать проверку ещё раз, бот дотягивает полный текст; не помогло — эскалация со скрином.

## Скидки, промокоды, рефералы

1. Лояльность по сумме пополнений: от 250 $ — 3 %, от 500 $ — 5 %, от 1000 $ — 7 %.
2. Промокод активируется в «Мой профиль» → «🎟 Активировать промокод». Балансный зачисляет сумму сразу, скидочный применяется к следующему заказу.
3. Один и тот же промокод активируется пользователем один раз; у промокода есть общий лимит активаций.
4. Скидки не суммируются: применяется максимальная из (лояльность, промокод, акция магазина).
5. Промокод франчайзи работает только в его боте; промокод платформы — во всех.
6. Рефералка главного бота: **50 % от прибыли платформы** с каждой завершённой покупки приглашённого (прибыль = сумма заказа − себестоимость у поставщика). С пополнений реферала начислений нет.
7. Старые реферальные связи, созданные до перехода на новую схему, работают по прежней: **25 % от суммы пополнений** реферала, с покупок — ничего. Модель у связи не меняется задним числом.
8. Реферальная связь фиксируется один раз, при первом входе по ссылке; сменить пригласившего нельзя.
9. Во франшизном боте процент задаёт его владелец: по умолчанию 25 %, диапазон 10–100 %, база — доход владельца бота, а не платформы. Отдельным рефералам он может выставить индивидуальный процент.
10. Реферальный заработок падает на баланс и тратится в магазине, отдельного вывода нет.
11. При возврате заказа реферальное начисление и прибыль франчайзи по нему снимаются.

## Партнёрские боты (франшиза) и API

1. «Создать партнерского бота»: @BotFather → `/newbot` → имя и username → токен → отправить токен в бота. Подключение бесплатное.
2. Базовая наценка платформы на товары — 50 % над ценой поставщика (значение админ-редактируемое, сейчас 50 %). Она уже включена в цены главного бота.
3. Доход франчайзи — его дополнительная наценка поверх базовой. По умолчанию 100 %, задаётся самим партнёром в диапазоне 0–500 %: общая наценка плюс, при желании, отдельные для товаров, прокси и SMS.
4. За приглашение владельца другого бота платформа платит 15 % от его дохода с наценки.
5. Партнёр управляет ботом из кабинета: наценка, промокоды, акция, реферальный процент, тексты, баннеры, статистика.
6. Вывод заработка партнёра — от 5 $ (USDT через XROCKET), запросом из кабинета.
7. Скидки партнёра (промокод, акция) оплачиваются из его наценки, доход платформы не уменьшают.
8. Ассортимент, выдача, баланс клиентов и поддержка у франшизного бота общие с главным.
9. API: `https://sousmarketfranchize.shop/api/v1`, описание методов — `…/docs/#api`, ключ выдаётся в разделе API профиля.
