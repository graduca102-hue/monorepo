# supplier-bot — @menupostavshukabot

Бот поставщиков SOUS MARKET. В профиле бота SOUS MARKET (@MarketPlaceABot) есть
URL-кнопка **«📦 Меню поставщика»**, она ведёт сюда.

## Что умеет

- **Заявка**: «что продаёте» + контакт → уходит админам (`ADMIN_IDS`) с кнопками
  ✅ Принять / ❌ Отклонить. Если админ ещё не запускал этого бота, уведомление
  приходит через бота SOUS MARKET (`NOTIFY_BOT_TOKEN`) с подсказкой открыть `/admin`.
- **/admin** — статистика и все заявки на рассмотрении с кнопками решения.
- **Меню поставщика** (после одобрения):
  - ➕ Выставить товар: категория (дерево из каталога SOUS MARKET,
    `CATALOG_URL`; если каталог пуст/недоступен — встроенный список) → название →
    описание → цена в $ с пояснением про наценку `MARKUP_PERCENT` (50%) → превью → сохранить.
  - Лимит **`MAX_CARDS_PER_CATEGORY` (5) активных карточек одного поставщика в одной
    категории** — проверяется при выборе категории и атомарно при сохранении.
  - 🗂 Мои товары → карточка → 📤 Загрузить товар (файл .txt ≤5 МБ или текст, одна
    строка = одна единица, ≤10 000 строк, повторы пропускаются) / 🗑 Удалить.
  - 📋 Условия, 🆘 Тех поддержка → @UniversallSupportBot.
- Админам приходит уведомление о каждой новой карточке.

**Не сделано**: карточки поставщиков пока **не выводятся на витрину SOUS MARKET** и
не продаются — это отдельный этап (показ в каталоге бота/мини-аппа, покупка с баланса,
выдача строки из `stock_items`, учёт выплат поставщику).

## Данные

SQLite `/opt/supplier-bot/data/supplier.db`: `suppliers` (заявки/статусы),
`products` (карточки, `price_usd` — цена поставщика, `markup_percent` — наценка на
момент создания), `stock_items` (строки товара, `sold_at` — для будущих продаж).

## Деплой (srv2, systemd `supplier-bot`, `/opt/supplier-bot`)

Собрать архив `app/ deploy/ requirements.txt`, залить в `/tmp/supplier-bot.tgz`
(+ при первом запуске `/tmp/supplier-bot.env`), выполнить `deploy/install.sh`:
бэкап кода и БД в `backups/<ts>`, venv, pip, unit, рестарт, проверка лога.

Логи: `journalctl -u supplier-bot -f`. Тесты: `python -m pytest tests`.
