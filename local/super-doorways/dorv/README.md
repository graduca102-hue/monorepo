# Telegram Bot Tool

Скрипт запускается через терминальное меню.

## Меню

1. Обновить `name / description / photo`
2. Собрать пользователей из `getUpdates`
3. Сделать дамп пользователей
4. Сделать рассылку по сохраненным пользователям
5. Настроить количество потоков
0. Выход

## Файлы

- `token.txt` - токены ботов, по одному в строке
- `name.txt` - имена ботов, по одному в строке
- `photo/` - аватарки ботов
- `config.json` - описание, short description и MTProto-настройки
- `users.json` - локальная база найденных пользователей
- `broadcast.txt` - текст для рассылки
- `dumps/` - сюда сохраняются дампы пользователей

## Как использовать

1. Запустите `python main.py`
2. При необходимости задайте число потоков через пункт `5`
3. Для сбора базы используйте пункт `2`
4. Для выгрузки в файлы используйте пункт `3`
5. Для рассылки используйте пункт `4`

## Потоки

Настройка потоков используется для:

- обновления профилей ботов
- рассылки сообщений

Сбор пользователей из `getUpdates` остается последовательным: сначала 1 бот, потом следующий.
Так безопаснее для больших баз и соответствует вашему требованию.

## Проверка токенов

Если Telegram возвращает `401 Unauthorized`, скрипт:

- перепроверяет токен до 5 раз
- если все 5 проверок дают `401`, удаляет токен из `token.txt`

## Важно

Полный список всех старых пользователей Telegram сам не отдает, если бот раньше их не сохранял.
Этот инструмент может:

- собрать пользователей из доступных `getUpdates`
- сохранить их локально в `users.json`
- использовать сохраненную базу для дампа и рассылки

`description_photo` остается в owner-mode через `mtproto`.
