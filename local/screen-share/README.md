# screen-share — демонстрация экрана ПК по ссылке

Живая картинка рабочего стола (MJPEG, ~12 fps) отдаётся по обычной ссылке —
как «демонстрация экрана» в Discord, только открывается в браузере на телефоне
или другом ПК. Звука нет, управления нет — только просмотр.

## Как работает

```
браузер  ->  http://31.77.145.160:<PubPort>/<token>      (relay.py на srv2)
         ->  srv2:127.0.0.1:<FwdPort>                     (SSH reverse-туннель)
         ->  ПК:127.0.0.1:<Port>   serve.py  ->  ffmpeg -f gdigrab -i desktop
```

- Cloudflare quick tunnel на этой сети заблокирован (QUIC и TLS к edge не проходят),
  поэтому выход наружу — через назначенный сервер **srv2**.
- Конфиг nginx/ssh на сервере **не меняется**: `relay.py` просто копируется в
  `/tmp` и запускается/убивается скриптами. Порт 8792 на srv2 доступен снаружи
  (внешнего фаервола нет, проверено).
- ffmpeg берётся из `D:\ffmpeg-master-latest-win64-gpl-shared\bin\ffmpeg.exe`.

## Запуск / остановка

```powershell
# запустить на 30 минут (по умолчанию), ссылка уйдёт хозяину в Telegram
pwsh -NoProfile -File project\screen-share\start.ps1

# другой срок / параметры
pwsh -NoProfile -File project\screen-share\start.ps1 -Minutes 120 -Fps 15 -Width 1600

# остановить сразу
pwsh -NoProfile -File project\screen-share\stop.ps1
```

`start.ps1` сам ставит отложенную остановку через `-Minutes` минут (отдельный
фоновый процесс `pwsh`, pid в `run\state.json`).

## Файлы

| файл        | что делает                                                        |
|-------------|------------------------------------------------------------------|
| `serve.py`  | локальный HTTP-сервер (только 127.0.0.1): страница + MJPEG-поток  |
| `tunnel.py` | paramiko: SSH к srv2, заливает и стартует `relay.py`, reverse-туннель |
| `relay.py`  | публичный TCP-релей на srv2: `0.0.0.0:PubPort -> 127.0.0.1:FwdPort` |
| `start.ps1` / `stop.ps1` | запуск/остановка всей цепочки + уведомление в Telegram |
| `run/`      | логи и `state.json` с pid-ами и текущей ссылкой                   |

## Безопасность

- Ссылка защищена только случайным токеном в пути (24 hex-символа).
- Трафик идёт по **HTTP без шифрования** — токен и картинка экрана видны тому,
  кто слушает канал. Для разовой демонстрации приемлемо; для постоянного
  использования нужно повесить на srv2 TLS (есть сертификат
  `31-77-145-160.sslip.io`) — см. `project\ideas.md`.
- `stop.ps1` глушит и локальные процессы, и релей на srv2, и удаляет его файлы
  из `/tmp`.
