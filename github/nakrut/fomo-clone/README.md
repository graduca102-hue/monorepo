# fomo.family — страница токена 1:1 + фейковый памп

Клон страницы `https://fomo.family/tokens/solana/6vRoghyPdwLuD6rqPeS26XfLEmvNJmDy3aViFWQ6BJbu`
(токен **BREAKING**) с работающей симуляцией роста.

## Как открыть

Просто откройте `index.html` в Chrome (двойной клик работает, `file://` поддерживается).
Если хочется без ограничений `file://`, можно поднять статику:

```powershell
python -m http.server 8899
# http://localhost:8899/index.html
```

Страница рассчитана на десктоп; при узком окне сам сайт показывает заглушку
«Download the app» — это его собственное поведение, оно сохранено как есть.
Комфортная ширина — от 1600px, при 1920px в шапке видны все 7 плиток статистики.

## Что откуда взялось

Разметка и стили — это реальный снимок страницы, снятый WebScrapBook
(`index.html`, `index_1.html`, `root-v2-*.css`, чанки TradingView `*.css`, картинки).
DOM не переписывался: скрипты находят элементы по их подписям
(«Market cap», «Liquidity», «No holders yet» и т.д.) и обновляют значения.

Цвета графика взяты пипеткой из захваченного canvas исходной страницы:
фон `#060510`, сетка `rgb(20,19,29)`, рост `rgb(33,201,94)`, падение `rgb(255,98,46)`.

## Как это устроено

**Время реальное.** `speed: 1`, свеча — 1 секунда, таймфрейм в тулбаре и в
легенде подписан `1s`. Возраст токена стартует с `1m` (`token.ageMinutes`) и
растёт на минуту каждую реальную минуту.

**Памп уже случился.** Вся волна лежит в истории — 96 секундных свечей,
разложенных как на скриншоте с $3.1M:

```
мёртвый участок → вертикаль (rampSeconds) → пила на верхах (rampEndsAgoSeconds) → сейчас
      ~7 свечей          ~32 свечи                    ~56 свечей
```

От `pump.mcStart` ($25) до `pump.mcNow` (случайно из диапазона, по умолчанию
$2.4–3.6M). После волны включается второй режим болтанки (`noiseTop`,
`pullbackDepthTop`): большие свечи, красные откаты и стенка объёма — а не
мёртвый график на $14. Вместе с историей достраиваются сделки, холдеры и
объёмы, поэтому таблицы и блок About заполнены с первой секунды.

**Область графика занимает всю высоту окна** (`chart.fillViewport`), поэтому
таблица Holders уезжает под сгиб — как на том же скриншоте. Разделитель под
графиком по-прежнему тянется мышью, после этого авторастяжка отключается.

**Все цифры — из одного слепка.** `sim.dexFeed()` считает пакет значений в
стиле dexscreener (цена, MC, ликвидность, 24H объём, холдеры, top 10,
изменения 5M/1H/4H/1D, buys/sells/buyers/sellers) и обновляет его **строго раз
в секунду** (`uiMs`). Шапка, блок About, таблицы и график читают именно его —
поэтому «Market cap» в шапке всегда совпадает с последней свечой на графике.

Цикл модели крутится на `setInterval`, а не на `requestAnimationFrame`: rAF
замирает, когда браузер не рисует кадры (вкладка в фоне, свёрнутое окно), и
цифры зависали бы. Шаг считается по реальному `dt`, так что время на графике не
отстаёт, а при возврате на вкладку страница догоняет сама.

**Тикер, название, адрес.** `token.symbol` — то, что белым в шапке,
`token.name` — серым под ним; оба подставляются в готовую вёрстку по строкам из
снимка (`captureSymbol` / `captureName`). Адрес при каждой загрузке новый
случайный base58 (`token.address: null` — поставьте строку, чтобы зафиксировать):
меняется короткая форма `6vRogh...Q6BJbu`, ссылки «Search on X» и то, что
копирует кнопка рядом с адресом.

**Курсы в футере настоящие.** GET к публичному API CoinGecko (`footerLive`) при
загрузке и потом каждые `footerRefreshMs` (15 с): BTC / ETH / SOL / HYPE
показывают текущую цену и суточное изменение как есть, плюс микродрожание
`footerJitter` (не дальше 0.025% от курса), чтобы цифры выглядели живыми.
Проверено, что запрос проходит и с `file://`. Нет сети или запрос заблокирован —
остаются значения из `CFG.footer` (снимок на 31.08.2026), без ошибок в консоли.

**Чего на странице больше нет.** Блок «Warning: N issues» удаляется целиком, а
кнопки Buy / Sell и суммы-пресеты сразу активны. Часы `18:47:03 UTC+3` в нижней
панели графика убраны (`chart.showClock`).

**Кошелёк в шапке.** Значения `<number-flow-react>` в снимке лежат в shadow DOM
и без библиотеки не рисуются — скрипт собирает строку обратно, поэтому видно
`$0,00 cash` и `$0,00`, как на живом сайте.

## Что именно меняется

**Шапка токена:** Market cap, Price (с подстрочным счётчиком нулей), 24H change,
24H Vol., Liquidity, Holders, Top 10 holding, возраст токена, `<title>` вкладки.

**График:** свечи 1s (последняя достраивается), гистограмма объёма, сетка,
автомасштаб шкалы цены, подписи времени с секундами, пунктир последней цены с
бейджем, значения `O H L C` и изменение в легенде. Курсор мыши рисует
перекрестие с подписями на осях. Кнопка `Price / MCap` в тулбаре переключает шкалу.

**Блок About:** 5M / 1H / 4H / 1D (кнопки переключают окно расчёта),
buys/sells, объёмы, buyers/sellers и полоски их соотношения.

**Таблицы:** `Holders` — топ кошельков с позицией, PnL, средним входом и тезисами;
`Swaps` — живая лента сделок с подсветкой новых строк. Вкладки переключаются.

**Левая панель:** список токенов из снимка (Watchlist, Trending, Most held и
т.д.), вкладка `Crypto` показывает BTC / ETH / SOL / HYPE с живыми курсами.

**Остальное:** курсы BTC/ETH/SOL/HYPE в футере, разделитель под графиком тянется мышью.

## Настройка

Всё в `fomo-config.js`, перезагрузка страницы применяет изменения.

```js
uiMs: 1000                  // как часто обновляются цифры (шапка, About, график)
token.ageMinutes: 1         // «1m» в шапке на момент открытия
token.address: null         // null => случайный адрес при каждой загрузке
pump.mcNow: [2.4e6, 3.6e6]  // капитализация, с которой открывается страница
pump.rampSeconds: 32        // длина вертикали в свечах-секундах
pump.rampEndsAgoSeconds: 56 // сколько «пилы на верхах» видно справа
pump.curve: 1.1             // >1 — сильнее «загиб вверх» в конце вертикали
pump.noiseTop / pullbackDepthTop            // размах свечей после волны
trades.ratePerMinPeak: 480                  // сделок в минуту на пике
history.bars: 96            // сколько секундных свечей нарисовано до «сейчас»
chart.intervalLabel: '1s'
chart.showClock: false      // часы в нижней панели графика
chart.fillViewport: true    // график на всю высоту окна
footerLive: true            // тянуть реальные курсы BTC/ETH/SOL/HYPE
```

Хотите памп побольше — поднимите `pump.mcNow`. Хотите больше «пилы» и короче
вертикаль — двигайте `rampSeconds` / `rampEndsAgoSeconds`, их сумма должна быть
меньше `history.bars`. Спокойнее свечи после волны — уменьшите `noiseTop`.

Модель в консоли доступна как `window.fomoSim`.

## Пересборка из снимка

`_build.py` заново копирует `index.html` / `index_1.html` из папки снимка,
срезает служебные атрибуты WebScrapBook и подключает скрипты. Путь к снимку
задан в константе `CAPTURE` внутри файла.

```powershell
python _build.py
```
