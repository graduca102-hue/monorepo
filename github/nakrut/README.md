# Telegram-бот накрутки

Рабочий прототип по предоставленным экранам: главное меню, проверка подписок,
профиль, реферальная система, ежедневный бонус, VIP-счётчик, промокоды и задания.
Задания и обязательная подписка интегрированы с Flyer API. Данные сохраняются в
SQLite (`bot.sqlite3`). Внешних Python-зависимостей нет.

## Запуск

1. Скопируйте `.env.example` в `.env`, укажите `BOT_TOKEN`, `FLYER_API_KEY`, `BOTOHUB_AUTH_TOKEN` и `SOCPROOF_API_KEY`.
2. При необходимости задайте резервные каналы в `FREE_SPONSORS` и
   `EARN_SPONSORS` в формате из примера.
3. Запустите:

```powershell
python bot.py
```

При наличии `FLYER_API_KEY` обязательная подписка использует `/get_tasks` и
`/check_task`. Без выполнения этих подписок кнопка бесплатной накрутки не
открывается.

Раздел `Заработать монеты` построен по блокам. По состоянию на `2026-08-29`
настроены 4 независимых блока по `2000` монет:
- `Блок 1` использует Flyer.
- `Блоки 2-4` используют BotoHub через `POST https://botohub.me/get-tasks`
  с заголовком `Auth`.

Награда за блок начисляется один раз в день после успешной проверки всех
спонсоров блока.

Кнопка «Ещё задания» использует Linkni. Бот добавляет к `LINKNI_APP_URL`
уникальный `sub_code` пользователя и ждёт webhook от Linkni. Награда
начисляется только после события `subscribed`, полученного на локальный
endpoint `LINKNI_WEBHOOK_PATH`. Для внешней работы этот endpoint нужно
опубликовать и указать в кабинете Linkni.

Платные заказы отправляются в `soc-proof.su` сразу после подтверждения в боте.
В локальной базе сохраняются внутренний номер заказа и номер заказа у поставщика.

По состоянию на 2026-08-29 витрина привязана к дешёвым услугам поставщика:
Telegram-подписчики — `458`, Telegram-подписчики без списаний — `1504`,
Telegram-реакции — `884`, Telegram-просмотры — `1565`, TikTok-подписчики — `444`,
TikTok-просмотры — `639`, TikTok-лайки — `539`.

Проверочные промокоды: `WELCOME` (+1000) и `START` (+500).
