# Rich Text Chess & Checkers для Telegram

Нативная P2P-игра в шахматы и русские шашки без Mini App. Вся партия находится внутри одного сообщения Telegram, построенного на Rich Messages из Bot API 10.3:

- доска — компактная таблица `InputRichBlockTable` 10×10 с координатами по четырём сторонам;
- каждая клетка — кнопка `RichTextButton` внутри таблицы;
- статус, история и управление — блоки того же Rich Message;
- пользователь отправляет приглашение через inline mode: `@ChessAndRoBot`;
- соперник нажимает «Присоединиться», после чего сообщение обновляется через `inline_message_id`;
- ход выполняется двумя нажатиями: фигура → клетка назначения.

Публичный домен, HTTPS и Web App не требуются. Бот работает через long polling.

## Возможности

- Шахматы: все легальные ходы, шах, мат, пат, рокировка, взятие на проходе, превращение и стандартные ничьи.
- Русские шашки: обязательное взятие, многоходовые серии, взятие назад, летающие дамки, превращение в серии и «турецкий удар».
- Серверная проверка каждого хода.
- Переворот доски, история ходов и подтверждение сдачи.
- Сохранение активных партий в `data/games.json` с атомарной записью.

## Запуск

Требуется Node.js 20+ и Bot API 10.3.

```bash
cp .env.example .env
npm install
npm test
npm start
```

`.env`:

```dotenv
BOT_TOKEN=токен_из_BotFather
BOT_USERNAME=ChessAndRoBot
DATA_FILE=./data/games.json
```

## BotFather

1. Выполните `/setinline` и выберите бота.
2. Укажите placeholder, например `Шахматы или шашки`.
3. Выполните `/setinlinefeedback`, выберите бота и установите `100%`. Это нужно для получения `inline_message_id` сразу после отправки приглашения.
4. Mini App настраивать не нужно.

После этого в любом чате введите:

```text
@ChessAndRoBot
```

Выберите шахматы или шашки и отправьте результат.

## Docker

```bash
docker compose up -d --build
```

Открывать порты не требуется — бот использует исходящее соединение с Telegram.

## Структура

```text
src/games/       правила и хранилище партий
src/telegram/    Rich Message, inline mode и callback-обработчики
src/index.js     запуск long polling
test/            тесты правил и структуры Rich Message
```

Rich Messages появились в Bot API 10.1, а интерактивные кнопки внутри них — в Bot API 10.3 от 24 августа 2026 года. Старые клиенты Telegram могут показать заглушку с предложением обновить приложение.
