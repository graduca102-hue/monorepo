API Документация

Документация по Public API и Reseller API для интеграции с вашими сервисами

Открыть в Postman

Базовый URL

https://vproxy.cc/public-api

Аутентификация

Получите JWT-токен через эндпоинт /token, затем используйте его в заголовке

Authorization: Bearer your_jwt_token_here

⚡ Важно

Использование фильтров по ASN, ZIP-кодам, городам и штатам удваивает расход трафика для каждого запроса.

🔐

Аутентификация

POST/token

Получить JWT-токен для аутентификации. Можно использовать username или email для входа.

Header:

Accept: text/plain

Request Body:

{
  "username": "username",
  "password": "password"
}
ParameterTypeRequiredDescription
usernamestring✓Имя пользователя или email
passwordstring✓Пароль

Пример запроса:

curl -X POST https://vproxy.cc/public-api/token \
  -H "Content-Type: application/json" \
  -d '{"username": "your_username", "password": "your_password"}'
🔗

Управление прокси

POST/balance

Получить баланс для указанного пула прокси. Требуется JWT-аутентификация.

Request Body:

{
  "pool": "residential"
}
ParameterTypeRequiredDescription
poolstring✓Тип пула: residential, datacenter, mobile, residential_premium
POST/proxy

Сгенерировать прокси с указанными параметрами. Требуется JWT-аутентификация.

Header:

Accept: text/plain

Request Body:

{
  "pool": "residential",
  "countries": ["fr", "ru"],
  "cities": ["newyork", "losangeles"],
  "states": ["northchili"],
  "asns": ["AS1234", "AS5678"],
  "zipcodes": ["10001", "90001"],
  "anonymous": "true",
  "type": "rotating",
  "protocol": "http",
  "format": "login:password@hostname:port",
  "quantity": 2,
  "sessionttl": 6
}
ParameterTypeRequiredDescription
poolstring✓Тип пула: residential, datacenter, mobile, residential_premium
countriesstring[]—Фильтр по странам
citiesstring[]—Фильтр по городам
statesstring[]—Фильтр по штатам
asnsstring[]—Фильтр по ASN
zipcodesstring[]—Фильтр по индексам
anonymousstring—Анонимные прокси: "true" или "false"
typestring—Тип прокси: rotating или sticky
protocolstring—Протокол: http, socks5
formatstring—Формат: login:password@hostname:port
quantityinteger—Количество прокси
sessionttlinteger—Время жизни сессии (сек)
🌍
