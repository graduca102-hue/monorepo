# Telegram-магазин цифровых товаров

Бот продаёт только выбранные разделы SOUS API:

- Instagram;
- YouTube;
- выделенные прокси;
- резидентские прокси;
- пакеты прокси-сервисов.

Пользователь пополняет внутренний баланс через Heleket, после чего покупает товар. Есть профиль, история заказов, промокоды, реферальная система и поддержка. Встроенная админка управляет ключами API, курсом, наценками, балансами, промокодами, рассылками и статистикой.

## Быстрый запуск

1. Установите Python 3.11+.
2. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN` и `ADMIN_IDS`.
3. Установите зависимости: `python -m pip install -r requirements.txt`.
4. Запустите: `python run.py`.
5. Откройте бота и отправьте `/admin`. В разделе «Ключи API и оплаты» укажите SOUS API key, Heleket merchant ID и Heleket payment API key.

Ключи, введённые в админке, шифруются. Ключ шифрования хранится отдельно в `.secret.key`; сохраните его вместе с резервной копией базы. Полные секреты бот никогда не показывает.

## Heleket и вебхук

Для автоматического зачисления нужен публичный HTTPS-адрес. Укажите его в админке как «Публичный URL» и направьте:

`POST https://ваш-домен/webhooks/heleket`

на порт приложения `8080`. Даже без публичного URL пользователь может зачислить оплату кнопкой «Проверить оплату», так как бот запрашивает статус счёта у Heleket.

Проверка подлинности вебхука выполняется по подписи Heleket; повторная доставка не начисляет баланс второй раз.

## Docker

Создайте `.env`, затем выполните `docker compose up -d --build`. База и ключ шифрования сохраняются в каталоге `data`.

## Важные настройки

- `USDT/RUB` — курс пересчёта закупочной цены поставщика в рубли.
- Наценки Instagram/YouTube и Proxy задаются отдельно.
- Резидентские прокси выдаются по умолчанию с параметрами: Украина, HTTP, rotating, 10 адресов. Эти параметры находятся в `app/handlers_user.py` и могут быть расширены отдельным мастером выбора.
- При однозначном отказе API зарезервированная сумма возвращается автоматически. При сетевом обрыве заказ получает статус «на проверке», чтобы исключить двойную выдачу.

## Проверка

Запуск тестов: `python -m unittest discover -s tests -v`.
